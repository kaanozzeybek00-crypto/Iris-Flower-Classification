Iris Flower Classification

Bu proje Iris veri seti kullanılarak çiçek türlerinin sınıflandırılmasını amaçlamaktadır.

Dataset Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Algorithms:
- Gaussian Naive Bayes
- Logistic Regression
- Support Vector Machine

Technologies:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

Results:
En yüksek doğruluk oranı Logistic Regression ve SVM modellerinde elde edilmiştir.
